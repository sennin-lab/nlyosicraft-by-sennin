# STATUS

## 現在の状態
- 無限ワールド（シード固定の自動生成）、昼夜サイクル（約8分）
- 体力・空腹・飽和度・自然回復・落下/溺水/飢餓ダメージ・死亡とリスポーン
- モブ: ゾンビ・スケルトン（矢）・クリーパー（爆発で地形破壊）・クモ（敵）、ブタ・ウシ・ニワトリ（動物）
- 持ち物（36枠）、2×2の作成、作業台（3×3）、かまど（精錬と燃料）
- 道具の段階（木・石・鉄）と耐久、採掘速度と適正道具による回収
- iPad（Safari / ホーム画面追加）向けのタッチ操作・レイアウト対応

## 実装の要点
- 夜は敵が湧き（最大12体）、昼は草原に動物が湧く（最大8体）。プレイヤーから20〜36ブロックの距離で湧き、64〜80ブロックを超えると消える
- 敵は16ブロック以内で追跡。ゾンビとクモは接触で攻撃、スケルトンは距離を保って矢を撃つ、クリーパーは近づいて導火し爆発
- ゾンビ・スケルトンは日中に屋外にいると燃える
- 戦闘: 剣・斧などの攻撃力で殴る。攻撃のたびに道具の耐久が減る
- 空腹: 歩行・ジャンプ・採掘・攻撃で疲労が溜まり、空腹が減る。空腹18以上で自然回復、0で飢餓ダメージ
- 食べ物: りんご・パン・生肉・焼き肉などを「置く」ボタンで食べる（空腹が満タンでは食べられない）
- 作業台・かまどは「置く」で開く。かまどは燃料（石炭・木材）で精錬（鉄鉱石→鉄インゴット、生肉→焼き肉、丸石→石、砂→ガラス）

- クラフト: 原木→板材（UI経由で4個）、作業台の表示と開閉、かまどの設置と開閉
- モブ: ゾンビの接触ダメージ、剣の攻撃と耐久減少、夜の湧き（8体）、クリーパーの爆発（地形破壊・プレイヤーへのダメージ・消滅）
- 死亡: 体力0で死亡画面、持ち物を開いたままでも死亡後は閉じられない、リスポーンで体力20
- iPad相当のタッチ: 破壊長押し（草→土を回収）、ジャンプ（約1.2ブロック）

## 今回の変更（段差・水中・画質・クラフト）
- 段差: 1ブロックの段は歩くと自動でジャンプして乗り越える（瞬間移動をやめた）。2ブロック以上の壁は登れない
- 水中: 胴体が水の中にあるかで判定（頭だけ水面から出た時の詰まりを解消）。岸に当たるとジャンプで水から上がれる。水中では空と霧が青く沈んだ色になり、見通しが短くなる
- 画質: ポーズメニューの「画質」で 標準（既定）→高（縦横2倍）→低→自動 を切り替え。標準は固定（以前の自動は重いと0.5倍まで下がっていた）。描画バッファの長辺は4096まで
- クラフト: 松明（石炭＋棒→4本、2x2可）、丸石の階段（作業台）、木のハーフブロック（作業台）を追加。松明・階段・ハーフブロックは形どおりに描画・当たり判定される
- 階段は向きを持たない（常に同じ向きの2段）。石と石炭を使う別レシピは未実装（内容の確認待ち）

## 既知の制限
- 地形と持ち物は保存されない（ページを再読込すると失われる）
- 死亡時に持ち物は消えず、落とさない
- モブのドロップは地面のアイテムにならず、直接持ち物へ入る
- 防具・チェスト・スニーク・ダッシュ（全力疾走）・ベッド・村・廃坑・モブの群れ行動は未実装
- 持ち物画面を開いている間はゲームが止まる（本家のシングルプレイとは異なる）
- 敵の見た目は箱モデル。アニメーションは歩行の振りのみ
- 実機の性能は未計測（検証環境はソフトウェアGPU）。モブが多いと描画が重くなる場合は描画距離を下げる
