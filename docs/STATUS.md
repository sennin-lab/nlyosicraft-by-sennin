# STATUS

## 現在の状態
- 無限ワールド（シード固定の自動生成）、ジャンプ、破壊、設置、ホットバーが動作
- iPad（Safari / ホーム画面追加）向けのタッチ操作・レイアウト対応
- 描画は端末のピクセル比（最大2倍）基準。負荷に応じて解像度を50〜100%で自動調整

## 実装済み
- 地形: 平原・森・砂漠・雪原・山（標高ベース）、海（海面62）、洞窟、鉱石（石炭・鉄・金・ダイヤ・銅）、木（オーク）、草・花・サボテン
- 物理: AABB衝突、重力、ジャンプ（高さ約1.25ブロック）、段差の自動上り（1ブロック）、水中の浮遊
- 操作（タッチ）: 左スティック移動、右側ドラッグで視点、「壊す」長押しで破壊（進捗リング）、「置く」タップ/連打で設置、「跳ぶ」
- 操作（PC）: WASD/矢印で移動、Space跳躍、マウス左長押しで破壊、右クリックで設置、右ドラッグで視点、1〜9/ホイールでスロット選択
- インベントリ: ホットバー9種（各64個で開始）。掘ったブロックはホットバーに入っている種類のみ回収
- クリエイティブ切替（ポーズメニュー）: 設置数無制限・破壊即時
- 一時停止: 画面を離れると自動で一時停止、ポーズメニューから新しいワールド・バグ報告

## 確認した項目（ヘッドレスChromium + タッチイベント再現）
- 起動時のエラーなし
- ジャンプ: 上昇 約1.19ブロック
- 歩行: 1秒で約4.4ブロック
- 段差: 1段は乗り越え、2段の壁では停止（衝突位置 z=45.3 を確認）
- 破壊: 草ブロックが消え、インベントリ 64→65
- 設置: 平地で草ブロックを設置、頭の位置と重なる場所は拒否
- iPad相当（1366x1024 / DPR2 / タッチ）: 破壊長押し・ジャンプ・スティック操作が実タッチで動作、横向き・縦向きのレイアウト確認

## 既知の制限
- 地形は保存されない（ページを再読込すると、編集内容は失われる）
- 敵MOB、空腹・体力、クラフト、かまど、チェストは未実装
- 鉱石・花・草は1種類ずつのみ回収できる（ホットバーの中身は固定）
- 実機の描画性能は未計測（検証環境はソフトウェアGPU）。負荷が高ければ描画距離（タッチ端末は3）を下げる
- 木・洞窟の生成は簡易版
