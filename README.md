# Voxel Survival（ブラウザ版 Minecraft風ゲーム）

## 概要
- **ビルド不要**: ES Modules と WebGL2 のみで動く静的サイトです。npm・バンドラ・サーバーコードは使いません。
- 対応: PC（Chrome / Safari / Edge）、iPad（iPadOS 15以降のSafari）

## ローカルでの動作確認
リポジトリのルートで以下を実行し、ブラウザで `http://localhost:8080` を開きます。

```bash
python3 -m http.server 8080
```

## iPadでの使い方
1. Safariで開く（共有ボタン → 「ホーム画面に追加」で全画面表示になります）
2. 画面左側をドラッグで移動、右側をなぞって視点
3. 右下「壊す」を長押しで破壊・攻撃、「置く」で設置・食べる・作業台やかまどを開く、「跳ぶ」でジャンプ
4. 画面下のホットバーをタップして道具やブロックを選択
5. 右上「持ち物」で持ち物・2×2の作成（作業台では3×3）。タップで拾う・置く・重ねる
6. 画面左上「||」でメニュー（新しいワールド、クリエイティブ切替、バグ報告）

## PCでの操作
- 移動: WASD / 矢印キー、ジャンプ: Space
- 破壊・攻撃: マウス左長押し（または F キー）、設置・使う: 右クリック（または E キー）
- 視点: 右ボタンをドラッグ、スロット: 数字キー 1〜9 またはホイール
- 持ち物: I キー、閉じる: Esc

## Render 配信設定
- 種別: Static Site
- Build Command: 空欄
- Publish Directory: `.`
- Branch: `main`
- ルーティング(rewrite): なし

クライアント側ルーティングを使わないため rewrite は不要です。`/*` を `index.html` に rewrite すると `/src/*.js` まで `index.html` になり、`type="module"` が壊れます。

## スマホでの操作（まとめ）
- 縦持ちでは横向きを案内します（「このまま遊ぶ」で閉じられます）
- 左でスティック移動、右をなぞって視点、右下「壊す」「置く」「跳ぶ」、上部「持ち物」
- 小さい画面ではボタンとホットバーを自動で小さくします

## 描画距離・画質
- ポーズメニュー（左上「||」）の「描画距離」で 2・3・4・6・8 チャンクを切り替えます（大きいほど重くなります）
- 同じメニューの「画質」で 標準・高（縦横2倍）・低・自動 を切り替えます
- どちらも端末ごとに保存されます

## ブロックのテクスチャを差し替える
Minecraft 公式のテクスチャは著作物のため本リポジトリには含めていません。ご自身で用意した画像（ご自身が使用権を持つもの）を次の場所に置くと、その絵が使われます。

- 置き場所: `assets/blocks/<タイル名>.png`（16x16 推奨。それ以外のサイズは16x16に縮小されます）
- タイル名の例: `stone`, `cobble`, `dirt`, `grass_top`, `grass_side`, `sand`, `gravel`, `oak_side`, `log_top`, `planks`, `leaves`, `water`, `glass`, `bricks`, `snow`, `ice`, `obsidian`, `furnace_top`, `furnace_side`, `crafting_top`, `crafting_side`
- 対応するタイル名はソース中の `TILE_NAMES`（`src/render/atlas.js`）に全て載っています
- 画像がないタイルは従来どおり手描き調の模様を使います
